# Freesky — sklep serwera Minecraft

Statyczna strona sklepu dla serwera **Freesky**.

- Adres serwera: `free1.gemhost.pl:31962`
- Plik strony: `index.html`
- Hosting: GitHub Pages

## Włączenie GitHub Pages

1. Wejdź w repozytorium: https://github.com/b50282546-cpu/Freesky-sklep
2. Otwórz **Settings → Pages**.
3. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
4. Ustaw branch `main` oraz folder `/(root)`, następnie kliknij **Save**.
5. Po zakończeniu publikacji strona powinna być dostępna pod adresem:
   https://b50282546-cpu.github.io/Freesky-sklep/

## Ważne

To wersja demonstracyjna front-endu. Koszyk działa w przeglądarce, ale **nie przyjmuje płatności, nie zapisuje zamówień na serwerze i nie dostarcza automatycznie rang/przedmiotów**. Przed sprzedażą trzeba skonfigurować backend, operatora płatności i bezpieczną integrację z serwerem Minecraft. Nie umieszczaj kluczy API ani haseł w plikach strony.
